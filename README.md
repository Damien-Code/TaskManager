# Taskmanager

## A sideproject of mine where you can have daily standups with your team and also create todo's to stay up-to-date.

## What does it do?:

<ul>
  <li>Create todo's, categories and set dates</li>
  <li>Create a team, and start with daily stand-ups</li>
  <li>Filter stand-ups on date and see who did what</li>
</ul>

## Why?

<p>At school we use Agile scrum and have many daily standups, but I always felt like I missed something. I needed a place to track my tasks and quickly note my progress and improvements for my teammates.
That is why I created this App. A place to keep track of your tasks, but also a place to have your daily standups.
It solved the problem for me, but also for my classmates. Right now we use this app for our schoolprojects!
No need for boring Word docs anymore.


### How to use the daily stand-up platform?

<ol>
  <li>Create an account</li>
  <li>Create a team and search for members</li>
  <li>Start writing your stand-ups</li>
  <li>Filter on date, and see who did what</li>
</ol>

### How to use the taskmanager?

<ol>
  <li>Create an account</li>
  <li>Create a todo or create a category to add to a todo</li>
  <li>Edit and mark todo's as done</li>
</ol>
